# Due lingue

Личное приложение для итальянского и испанского: тексты с переводом по нажатию,
упражнения с проверкой по ключу и через ИИ (DeepSeek), аудио к урокам, работа без сети.

Уроки и аудио в репозиторий не кладутся: они загружаются в приложение
на каждом устройстве (вкладка «Файлы») и хранятся только там.

## Как обновить приложение
1. Заменить файлы в репозитории.
2. В `sw.js` увеличить версию: `due-lingue-v1` → `due-lingue-v2`.
